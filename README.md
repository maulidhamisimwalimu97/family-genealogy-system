## 📖 System Overview

The **Family Genealogy System** is designed to help families manage and visualize their genealogy trees in a simple, efficient, and organized way.  
The system allows users to:

- Create and manage family trees
- Store detailed information about generations
- Provide services based on user payments
- Direct management of payments and services to Co-Founder or Admin
- Simplify data management, visualization, and user hierarchy
- Quickly access family information and communicate via messages or live meetings

This system aims to give families a complete overview of their lineage, helping users understand family history and relationships at a glance.

---

## 💻 Technologies Used

- **Backend:** Node.js, Express.js, MySQL  
- **Frontend:** HTML5, CSS, SCSS, JavaScript  
- **Authentication & Security:** bcryptjs, jsonwebtoken  
- **Development Tools:** nodemon, dotenv, cors
